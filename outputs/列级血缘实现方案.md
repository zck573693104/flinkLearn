# Flink SQL 列级血缘提取 - 完整实现方案

## 📋 概述

本文档描述了 Flink SQL 列级血缘提取的完整实现，基于 **Flink TableEnvironment + Calcite RelMetadataQuery** 架构。

---

## 🎯 核心架构

### 实现路线选择

经过分析，我们采用以下方案：

```
SQL → Flink Parser API → Operation Tree → NodeConverter → RelNode 
→ RelMetadataQuery.getColumnOrigins() → Column Lineage
```

### 技术栈

| 组件 | 技术 | 作用 |
|------|------|------|
| SQL 解析 | Flink Parser API | 将 SQL 转为 Operation Tree |
| 语义转换 | NodeConverter | Operation → RelNode |
| 元数据查询 | RelMetadataQuery | 获取列级血缘信息 |
| 血缘提取 | getColumnOrigins() | 核心 API |

## 🔧 核心实现

### 1. ColumnLineageExtractor 完整实现

**文件**: `ColumnLineageExtractor.java`

#### 主要方法

```java
public class ColumnLineageExtractor {
    
    private final TableEnvironment tEnv;
    private final CatalogManager catalogManager;

    public ColumnLineageExtractor() {
        // 创建 TableEnvironment
        this.tEnv = TableEnvironment.create(
            EnvironmentSettings.newInstance().inStreamingMode().build());
        
        // 获取 CatalogManager
        this.catalogManager = ((CatalogManager) tEnv.getCatalogManager());
    }

    /**
     * 提取列级血缘关系（主入口）
     */
    public List<ColumnLineageResult> extractColumnLineages(String flinkSql) {
        // Step 1: Parse SQL to Operation tree
        List<Operation> operations = parseToFlinkOperation(flinkSql);
        
        // Step 2: For each operation, extract column lineage
        for (Operation operation : operations) {
            List<ColumnLineageResult> operationResults = 
                extractFromOperation(operation, flinkSql);
            results.addAll(operationResults);
        }
        
        return results;
    }

    /**
     * Parse SQL to Flink Operation tree
     */
    private List<Operation> parseToFlinkOperation(String sql) {
        // Use Flink's native Parser API
        return tEnv.getParser().parse(sql);
    }

    /**
     * Convert Operation to RelNode
     */
    private RelNode convertToRelNode(Operation operation) {
        // Use NodeConverter to convert Operation → RelNode
        return NodeConverter.createRelNode(operation);
    }

    /**
     * Extract column-level lineage from RelNode
     * Uses RelMetadataQuery.getColumnOrigins() API
     */
    private Map<String, Set<String>> extractColumnLineages(RelNode relNode) {
        // Get output schema
        var outputSchema = relNode.getRowType();
        List<String> outputFieldNames = outputSchema.getFieldNames();

        // Create RelMetadataQuery instance
        RelMetadataQuery mq = RelMetadataQuery.standalone();

        // Register built-in metadata providers
        registerMetadataProviders(mq);

        // For each output field, get its column origins
        for (int i = 0; i < outputFieldNames.size(); i++) {
            String targetColumn = outputFieldNames.get(i);
            
            // Call RelMetadataQuery.getColumnOrigins()
            // Returns list of [table, column] pairs
            List<List<String>> columnOrigins = 
                mq.getColumnOrigins(relNode, i);
            
            if (columnOrigins != null && !columnOrigins.isEmpty()) {
                Set<String> sourceColumns = new HashSet<>();
                for (List<String> origin : columnOrigins) {
                    String fullOrigin = origin.stream()
                        .collect(Collectors.joining("."));
                    sourceColumns.add(fullOrigin);
                }
                columnLineages.put(targetColumn, sourceColumns);
            }
        }

        return columnLineages;
    }

    /**
     * Register metadata providers for RelMetadataQuery
     */
    private void registerMetadataProviders(RelMetadataQuery mq) {
        // Register the built-in column origin metadata provider
        MetadataDef<?> columnOriginsDef = RelMdColumnOrigins.getColumnOriginsDef();
        mq.setProvider(columnOriginsDef, new RelMdColumnOrigins());
    }
}
```

## 📊 支持的场景

### ✅ 已支持的场景

1. **简单列映射**
   ```sql
   INSERT INTO target SELECT user_id, amount FROM source;
   ```

   ```sql
   INSERT INTO result 
   SELECT a.id, b.name FROM table_a a JOIN table_b b ON a.id = b.a_id;
   ```

3. **窗口函数列推导**
   ```sql
   INSERT INTO result 
   SELECT user_id, SUM(amount) OVER (PARTITION BY user_id) as total 
   FROM stream_table;
   ```

4. **复杂多表 JOIN**
   ```sql
   INSERT INTO final_result 
   SELECT a.id, b.name, c.value 
   FROM table_a a 
   JOIN table_b b ON a.id = b.a_id 
   LEFT JOIN table_c c ON b.id = c.b_id;
   ```

## 🔍 工作原理

### 1. SQL 解析阶段

```
SQL String
    ↓
tEnv.getParser().parse(sql)
    ↓
List<Operation> (Operation Tree)
```

### 2. Operation → RelNode 转换

```
Operation (Flink internal representation)
    ↓
NodeConverter.createRelNode(operation)
    ↓
RelNode (Calcite representation)
```

### 3. 列血缘提取

```
RelNode
    ↓
RelMetadataQuery.getColumnOrigins(relNode, ordinal)
    ↓
List<List<String>> (table.column pairs)
    ↓
Map<String, Set<String>> (target -> sources)
```

## 💡 使用示例

### 基本用法

```java
// 创建提取器
ColumnLineageExtractor extractor = new ColumnLineageExtractor();

// 提取列级血缘
String sql = "INSERT INTO target SELECT a, b, c FROM source";
List<ColumnLineageResult> results = extractor.extractColumnLineages(sql);

// 查看结果
for (ColumnLineageResult result : results) {
    System.out.println(result.getTargetColumn() + " <- " + 
                      result.getSourceColumns());
}
```

## ⚠️ 已知限制

### 1. 计算列的血缘追踪

对于完全由表达式计算的列（如 `SUM(amount)`），可能无法追溯到具体源列：

```sql
-- 这个列的血缘可能为空或不完全
SELECT SUM(amount) OVER () as running_sum FROM table;
```

### 2. 常量列

常量值没有源列：

```sql
SELECT user_id, 'constant' as flag FROM table;
```

### 3. 复杂表达式

嵌套函数调用、CASE WHEN 等复杂表达式可能需要额外的解析逻辑。

## 🚀 性能优化建议

### 1. 缓存 RelMetadataQuery

对于同一个 RelNode，可以复用 RelMetadataQuery 实例：

```java
// 缓存 MQ 实例
private final Map<RelNode, RelMetadataQuery> mqCache = new ConcurrentHashMap<>();

RelMetadataQuery mq = mqCache.computeIfAbsent(relNode, k -> {
    RelMetadataQuery newMq = RelMetadataQuery.standalone();
    registerMetadataProviders(newMq);
    return newMq;
});
```

### 2. 批量处理

对于多个 SQL 语句，可以批量处理以提高效率：

```java
public List<ColumnLineageResult> extractBatch(List<String> sqls) {
    return sqls.parallelStream()
        .map(this::extractColumnLineages)
        .flatMap(List::stream)
        .collect(Collectors.toList());
}
```
