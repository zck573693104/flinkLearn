# 列级血缘提取实现总结

## 1. 实现概述

本次迭代实现了基于 JSQLParser 的通用列级血缘提取方案，支持 Flink、Spark、Presto 三种 SQL 引擎。

### 核心技术栈
- **JSQLParser 5.0**: SQL 文本解析器，提供 AST 解析能力
- **正则表达式**: 辅助提取表和列信息
- **通用提取器架构**: 统一接口，多引擎支持

## 2. 主要文件

### 2.1 核心实现

#### JSQLParserUtils.java
**位置**: `src/main/java/com/bigdata/lineage/parser/JSQLParserUtils.java`

**功能**: 
- SQL 文本解析工具类
- 提取表名（FROM, JOIN, INSERT INTO）
- 识别 SQL 类型（INSERT/SELECT/CREATE/DROP/ALTER）
- 移除 SQL 注释

**关键方法**:
```java
// 提取所有表名
public static Set<String> extractTables(String sql)

// 获取 SQL 类型
public static String getSQLType(String sql)

// 判断是否为 INSERT 语句
public static boolean isInsertStatement(String sql)
```

#### FlinkSQLLineageExtractor.java
**位置**: `src/main/java/com/bigdata/lineage/parser/FlinkSQLLineageExtractor.java`

**功能**:
- 表级血缘提取（使用 StreamTableEnvironment + JSQLParser fallback）
- 列级血缘提取（基于正则表达式解析 SELECT 子句）
- 置信度评分（0.85-0.95）

**列级血缘实现**:
```java
public List<ColumnLineageResult> extractColumnLineages(String flinkSql)
```

提取逻辑：
1. 使用 JSQLParserUtils.extractTables() 获取源表
2. 解析 INSERT INTO ... SELECT 语句
3. 从 SELECT 子句中提取列映射关系
4. 识别别名（AS）、函数调用、简单列引用

#### SparkSQLLineageExtractor.java
**位置**: `src/main/java/com/bigdata/lineage/parser/SparkSQLLineageExtractor.java`

**功能**:
- 与 Flink 类似的列级血缘提取
- 支持 INSERT OVERWRITE 语法
- 置信度评分（0.8-0.9）

#### PrestoSQLLineageExtractor.java
**位置**: `src/main/java/com/bigdata/lineage/parser/PrestoSQLLineageExtractor.java`

**功能**:
- 通用 SQL 解析（不依赖 Presto 原生 API）
- 列级血缘提取
- 置信度评分（0.8-0.9）

## 3. 列级血缘提取算法

### 3.1 基本流程

```
输入 SQL → 识别 SQL 类型 → 提取目标表 → 解析 SELECT 子句 → 提取列映射
```

### 3.2 列映射识别

#### 情况 1: 简单列引用
```sql
INSERT INTO target SELECT user_id, name FROM source
```
- Source Column: `user_id`
- Target Column: `user_id`
- Transformation: null

#### 情况 2: 带别名
```sql
INSERT INTO target SELECT user_id AS uid FROM source
```
- Source Column: `user_id`
- Target Column: `uid`
- Transformation: `alias:uid`

#### 情况 3: 函数调用
```sql
INSERT INTO target SELECT COUNT(*) as cnt FROM source
```
- Source Column: `COUNT`
- Target Column: `cnt`
- Transformation: `function:COUNT(*)`

#### 情况 4: 全量列
```sql
INSERT INTO target SELECT * FROM source
```
- Source Column: `*`
- Target Column: `*`
- Transformation: `star_mapping`

### 3.3 置信度评分规则

| 场景 | 置信度 | 说明 |
|------|--------|------|
| Flink 原生 API | 0.95 | 使用 Flink TableEnvironment |
| JSQLParser 解析 | 0.85-0.9 | 文本解析，可能遗漏复杂语法 |
| SELECT * | 0.8 | 无法确定具体列映射 |

## 4. 技术挑战与解决方案

### 4.1 JSQLParser 版本兼容性

**问题**: JSQLParser 4.9 和 5.0 API 差异较大

**解决方案**:
- 选择 JSQLParser 5.0
- 使用正则表达式作为主要解析手段
- 避免依赖复杂的 AST 遍历

### 4.2 Flink StreamTableEnvironment 初始化失败

**问题**: 需要 planner module 在 classpath 上

**解决方案**:
- 使用 JSQLParser fallback 方案
- 所有引擎统一使用文本解析
- 文档说明 Flink 完整集成的条件

### 4.3 复杂 SQL 语法支持

**当前支持**:
- ✅ INSERT INTO ... SELECT
- ✅ SELECT ... FROM ... JOIN
- ✅ GROUP BY
- ✅ 函数调用
- ✅ 别名（AS）

**暂不支持**:
- ⚠️ CTE (WITH 子句) - 部分支持
- ⚠️ 子查询 - 有限支持
- ⚠️ UNION/INTERSECT - 部分支持

## 5. 使用示例

### 5.1 基本用法

```java
// 创建提取器
SparkSQLLineageExtractor extractor = new SparkSQLLineageExtractor();

// 提取表级血缘
String sql = "INSERT INTO target SELECT a, b FROM source";
List<TableLineageResult> tableResults = extractor.extractTableLineages(sql);

// 提取列级血缘
List<ColumnLineageResult> columnResults = extractor.extractColumnLineages(sql);

// 输出结果
for (ColumnLineageResult col : columnResults) {
    System.out.println(col.getSourceColumn() + " -> " + col.getTargetColumn());
}
```

### 5.2 跨引擎使用

```java
// 同一 SQL 可在不同引擎中使用
String sql = "INSERT INTO result SELECT id, name FROM users";

// Flink
FlinkSQLLineageExtractor flink = new FlinkSQLLineageExtractor();
var flinkCols = flink.extractColumnLineages(sql);

// Spark
SparkSQLLineageExtractor spark = new SparkSQLLineageExtractor();
var sparkCols = spark.extractColumnLineages(sql);

// Presto
PrestoSQLLineageExtractor presto = new PrestoSQLLineageExtractor();
var prestoCols = presto.extractColumnLineages(sql);
```
